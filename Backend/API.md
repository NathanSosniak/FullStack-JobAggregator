# Routes de l'API

| Route                | Méthode | Protégée | Description                                  |
| :------------------- | :------ | :------- | :------------------------------------------- |
| Route                | Méthode | Protégée | Description                                  |
| /login               | POST    | non      | connecter un utilisateur                     |
| /register            | POST    | oui      | enregistrer un utilisateur                   |
| /user                | GET     | non      | récupérer les informations d'un utilisateur  |
| /stack_offer?filters | GET     | non      |  récupérer les annonces de la page d'accueil |
